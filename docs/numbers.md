## 3. 局限

- 测试 Agent 每种配置只跑了 1 遍（Haiku 混合跑了 2 遍），检出率差一两个缺陷就是 7 个百分点，配置之间的差异不显著，不下“谁更好”的结论。
- 靶子是自己写的，缺陷也是自己植入的：能说明方法有效，不代表在真实系统上的检出率。下一步是在开源 Web 应用的本地副本上跑，以维护者确认数作为外部证据。
- 录单的单据是生成的，版式只有三种；难题集上的差异来自 20 张单据，样本小。
- Haiku 有 2 轮测试探索被内容过滤中断（问题日志 P8），已用 `--resume` 补跑完。
